# 🌊 Visit Rio - Background Animation Project

A modern landing page built with **React**, **Vite**, and **Tailwind CSS**, focused on visual performance and high frame-count optimization for dynamic background animations.

## 🚀 Built With

- **React** (Core UI library)
- **Vite** (Ultra-fast bundler and dev server)
- **Tailwind CSS** (Styling and responsive design)
- **Sharp** (Image processing and optimization via Node.js)
- **GitHub Pages** (Global CDN hosting and distribution)
